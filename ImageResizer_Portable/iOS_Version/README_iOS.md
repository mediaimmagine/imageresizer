# Image Resizer for iOS

This version is designed to run on iOS devices (iPhone/iPad) using the Pythonista app.

## Requirements
- iOS 13.0 or later (compatible with devices from 2020+)
- Pythonista app from the App Store
- Pythonista 3.0 or later

## Installation
1. Install Pythonista from the App Store
2. Open Pythonista
3. Copy the `image_resizer_ios.py` file to Pythonista
4. Run the script

## Features
- Select images from your Photos library
- Resize to common presets (HD, Full HD, Instagram, etc.)
- Adjust quality settings
- Save resized images back to Photos
- Simple, touch-friendly interface

## Usage
1. Tap "Select Image from Photos" to choose an image
2. Set your target dimensions or use presets
3. Adjust quality if needed
4. Tap "Resize & Save to Photos" to process and save

The resized image will be saved to your Photos library with the prefix "trieste@news_".
